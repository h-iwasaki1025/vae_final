# VAE Final Project (`vae_final`)

このプロジェクトは、UNIX哲学に基づき、再現性と透明性、引き継ぎやすさを重視して設計されています。

## ディレクトリ構造

- `01_config/`: 環境設定・ハイパーパラメータ・依存パッケージ管理
- `02_data/`: データ格納用
  - `raw/`: 一次データ（非破壊・読み取り専用）
  - `interim/`: 中間生成データ
  - `processed/`: 学習・評価用処理済みデータ
- `03_src/`: ソースコード・共通モジュール（再利用可能な関数・モデル定義）
- `04_bin/`: シェルから呼び出す各種実行用パイプラインスクリプト (CLI)
- `05_experiments/`: 実験エントリーポイント・学習スクリプト
- `06_results/`: 評価結果、生成画像、モデルのチェックポイント
- `07_docs/`: Obsidian連動メモ・実験ログ・引き継ぎ用ドキュメント
